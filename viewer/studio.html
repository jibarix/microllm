This page starts training on your computer, so it needs the small local program that comes with microllm. In the microllm folder, double-click START_HERE.bat (Windows) or START_HERE.command (Mac), or run cargo run --release in a terminal.

Your turn Train my first model A small transformer reads Shakespeare and learns to write like it, on this computer, in about 2 minutes. A live view opens in a new tab so you can watch the text go from noise to Shakespeare-shaped lines. Afterwards it measures the valley training walked down (about a minute more).
Training is the one part that is not gentle on your computer.
  • It keeps the processor (and the graphics card, with GPU) busy for the whole run. The computer can get slow, hot and loud.
  • The studio starts it at low priority and suggests settings below what this machine can do, but estimates can be wrong. If memory runs out the system can freeze, or the operating system can end the run, or, on Windows, close the window the studio runs in.
  • Stopping a run leaves it unfinished in runs/; finished runs open in Past trainings.
  • Built and tested on Windows. On macOS and Linux it should run on the processor only; that is untested.

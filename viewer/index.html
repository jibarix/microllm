          Every merge, in the order learned

          BPE starts from single characters and repeatedly glues together the pair of adjacent tokens seen most often in the train split, making it a new token. Count = how many times that pair occurred when it was merged.

          Playground: the trained model, running in your browser

          The final parameters (runs/RUN/model.js) are loaded and the model's forward pass is recomputed here in JavaScript. Before anything is shown it must reproduce, number for number, the scores the Rust code wrote next to them.

          How temperature changes the writing

          The prompt above is continued once per temperature. Every run draws the same random numbers (from the seed), so temperature is the only difference. Temperature divides the scores before the softmax: below 1 the likely tokens get likelier, above 1 the distribution flattens. 0 is the limit from above, always the single most likely token (greedy; the seed no longer matters). A negative temperature reverses the ranking, so the least likely tokens become the most likely: near 0 from below it always picks the single least likely one. Under each text: the full model's surprise at it (bits per character at temperature 1; real validation text scores about the model's benchmark), the share of distinct words, and the share of word 3-grams that repeat an earlier one.

          Logit lens: the guess after each block

          The last position's residual stream after each block, sent straight through the final layer norm and output layer, as if the model stopped there. It shows at which depth the final answer forms.

          Switch heads off

          Unchecked heads have their output zeroed before it is mixed back into the residual stream (exactly what the trainer's head ablation does). Every result on this page is recomputed without them.

          Is the math right? Gradient checks

          Before training, every operation's gradient (and the real model code, shrunk) is checked against a brute-force estimate: nudge each number up and down by 0.000001 and watch how the loss moves. If backprop disagrees, training refuses to start.

          Selected invariants at this step

          Identities that must hold between the recorded numbers, recomputed here in your browser. They cover the output layer, the parameter gradients and the optimizer, but not every number of the step. Missing or non-finite numbers count as a failure, never a pass.
